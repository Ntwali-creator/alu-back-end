Python scripts to fetch and export employee TODO data from REST API.

## Files

- `0-gather_data_from_an_API.py` - Display employee TODO progress
- 
- `1-export_to_CSV.py` - Export to CSV
- 
- `2-export_to_JSON.py` - Export to JSON
- 
- `3-dictionary_of_list_of_dictionaries.py` - Export all employees to JSON
- 

## Usage

```bash

python3 api/0-gather_data_from_an_API.py 2

python3 api/1-export_to_CSV.py 2

python3 api/2-export_to_JSON.py 2

python3 api/3-dictionary_of_list_of_dictionaries.py
